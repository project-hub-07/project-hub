
# 📦 Blinkit Sales Dashboard 

 **Power BI dashboard project** for **Blinkit**, an on-demand delivery service, with the aim of providing actionable business insights into **sales performance, item distribution, outlet behavior**, and **customer ratings**.

---

## 📊 Project Overview

This dashboard analyzes product-level and outlet-level data across multiple dimensions including:

- Total sales revenue and item volume
- Outlet performance by size and location (Tier 1, 2, 3)
- Fat content distribution
- Item types and popularity
- Sales trends over time
- Average rating by outlet type

---

## 📌 Key Insights

- **Total Sales:** $1.20M across 8523 items.
- **Top Performing Outlet Type:** Supermarket Type1, contributing **$787.55K** in sales with a rating of **4.0**.
- **Outlet Size Analysis:** Large outlets generate the most sales, peaking at **$507.90K**.
- **Item Type Analysis:** Fruits & Vegetables and Snack Foods are the most popular categories.
- **Sales Trend:** Sales peaked in 2018 with **$205K**.
- **Outlet Tier Impact:** Tier 3 outlets contribute the highest sales at **$472.13K**.
- **Fat Content:** Regular fat items dominate inventory with 6K+ items.

---

## 🔍 Features

- **Dynamic filters** for outlet type, size, and item type.
- Drill-downs by:
  - Outlet location (Tier 1/2/3)
  - Outlet size (Small, Medium, High)
  - Fat content (Low/Regular)
- Visualizations include:
  - Bar charts, line graphs, donut charts, and KPI cards.
  - Tabular summary with key performance metrics per outlet type.

---

## 🛠️ Tools & Technologies

- **Power BI Desktop**
- Data Cleaning & Modeling in Power Query
- DAX for calculated measures and metrics
